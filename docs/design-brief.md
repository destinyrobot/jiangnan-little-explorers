# 设计简报 / Design Brief

**项目名称**：江南小小探索家
**英文名**：Little Explorers · Jiangnan
**项目类型**：个人概念项目 / Personal Concept Project（非商业委托、无真实客户）
**用途**：应聘「研学周边设计师」长期兼职岗位的能力参考作品

---

## 01 项目定位

面向 7～14 岁儿童及亲子家庭的**江南城市研学**主题文创周边系列。
以「探索 + 自然观察 + 江南水乡文化」为叙事，构建一套可延展的 IP 视觉系统，
并落地为 6 个可量产逻辑清晰的 SKU。

设计目标不是"好看的插画"，而是**一套能从 IP 走到 SKU 的完整系列设计**。

## 02 目标用户

| 维度 | 描述 |
| --- | --- |
| 直接使用者 | 7～14 岁儿童（研学营 / 亲子旅行） |
| 购买决策者 | 30～45 岁父母、研学机构带队老师 |
| 使用场景 | 研学出行、课堂记录、居家收纳、日常携带 |
| 审美期待 | 家长要"有品质不幼稚"，孩子要"可爱有角色" |

## 03 设计关键词

```
江南  ·  水乡  ·  园林  ·  古桥  ·  河道  ·  乌篷船
研学  ·  探索  ·  放大镜  ·  地图  ·  记录本
儿童  ·  亲子  ·  自然  ·  文化  ·  旅行
```

**风格约束（Do / Don't）**

- ✅ 清新、年轻、有教育感
- ✅ 有文创产品感与克制的高级感
- ✅ 儿童友好但不幼儿园
- ❌ 不像学校宣传册
- ❌ 不像廉价旅游纪念品
- ❌ 不模仿任何现有 IP，角色必须原创
- ❌ 不堆砌元素（每张画面 ≤ 3 个主元素）

## 04 视觉方向

**一句话定调**：
> Modern Flat Illustration × 轻手绘质感 × 江南水乡色谱
> （现代扁平插画 + 纸质颗粒 + 桥青 / 荷绿 / 柿橘的江南配色）

- **造型语言**：圆角几何 + 无粗黑描边；主体靠色块分层，暗部用同色系加深，不用纯黑阴影。
- **质感**：极轻的纸纹与噪点，让画面"像印刷品"而不是"像屏幕渐变"。
- **构图**：大留白、明确视觉焦点、单一地平线；产品图统一使用同一视角与同一投影角度。
- **文字**：全部由 HTML / SVG 排版，不依赖图像模型生成中文字（避免乱码）。

## 05 色彩系统（5 主色）

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 墨蓝 Ink | `#26364F` | 正文、头发、深色块、描边替代 |
| 河青 Canal | `#2E7D77` | 主品牌色：河道 / 桥 / 主视觉 |
| 荷绿 Lotus | `#79B473` | 自然 / 小荷 / 辅助色 |
| 柿橘 Persimmon | `#E9793B` | 强调色 / 背包 / 活力点 |
| 宣米 Rice Paper | `#F4ECDD` | 底色 / 纸张 |

**辅助色（不计入主色）**：纯白 `#FFFFFF`、青浅调 `#DCEDEA`、砖灰 `#C8CFCB`。

**比例建议**：底色 60% / 河青+荷绿 25% / 墨蓝 10% / 柿橘 5%。

## 06 字体建议

| 层级 | 中文 | 西文 | 用法 |
| --- | --- | --- | --- |
| Display | 苹方 / 思源黑体 Bold | Helvetica Neue Bold | 大标题、章节号 |
| Accent | — | Georgia *Italic* | 英文副标、装饰性短句 |
| Label | 苹方 Medium | Helvetica Neue，大写 + 字距 0.18em | 眉题、SKU 编号、图注 |

## 07 IP 角色

### 小舟 Xiaozhou（角色 A）
喜欢探索江南水乡的小男孩。
- 小型研学背包（柿橘）、地图 / 放大镜道具
- 河青拼袖上衣 + 墨蓝短裤，户外探索感
- 表情友善、自信，眉毛上扬

### 小荷 Xiaohe（角色 B）
喜欢观察自然的小女孩。
- 观察记录本 / 荷叶道具，荷绿连衣裙
- 发间荷叶形发夹，活泼但不幼稚
- 表情好奇、微微侧头

**统一规范**：同一头部比例（约 1:2.9 身头比）、同一肤色 `#F7DCC4`、同一眼型与腮红、同一轮廓语言、同一无描边扁平上色方式。可单独使用、可组合使用。

## 08 SKU 规划（6 件）

| SKU | 产品 | 设计重点 | 主色占比 |
| --- | --- | --- | --- |
| 01 | 研学帆布袋 Canvas Bag | 正面大幅路线图构图 + 角色压角，底部品牌条 | 河青 |
| 02 | 儿童/亲子水杯 Water Bottle | 环绕式腰带图案，杯身竖排留白，双色杯盖 | 荷绿 |
| 03 | 研学笔记本 Notebook | 封面几何开窗 + 书脊色带，烫印感 Logo | 河青 |
| 04 | 贴纸套装 Sticker Set | 12 枚异形贴纸网格，角色 / 图标 / 徽标混排 | 多色均衡 |
| 05 | 徽章 / 冰箱贴 Badge & Magnet | 3 枚圆形金属边徽章，独立底卡 | 柿橘 |
| 06 | 研学 T-shirt / Cap | 衣身大面积留白 + 左胸小标 + 背部大图；帽子同色系 | 墨蓝 |

**系列化原则**：同一角色比例、同一配色比例、同一构图重心（左上起）、同一投影角度（左上光 45°）、同一画面留白率（≥ 35%）。

## 10 内容性质声明
