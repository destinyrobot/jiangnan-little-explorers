01

设计概念

Design Concept

设计目标不是"好看的插画"，而是一套能从 IP 走到 SKU 的完整系列设计： 叙事上以「探索 + 自然观察 + 江南水乡文化」为线索，落地为 6 件可量产逻辑清晰的周边。

Modern Flat Illustration × 轻手绘质感 × 江南水乡色谱

现代扁平插画 + 纸质颗粒 + 桥青 / 荷绿 / 柿橘的江南配色

Target Users · 目标用户

直接使用者
7–14 岁儿童（研学营 / 亲子旅行）
购买决策者
30–45 岁父母、研学机构带队老师
使用场景
研学出行、课堂记录、居家收纳、日常携带
审美期待
家长要"有品质不幼稚"，孩子要"可爱有角色"

DO · 风格约束

  • 清新、年轻、有教育感
  • 有文创产品感与克制的高级感
  • 儿童友好但不幼儿园

DON'T · 边界

  • 不像学校宣传册、不像廉价旅游纪念品
  • 不模仿任何现有 IP，角色必须原创
  • 不堆砌元素（每张画面 ≤ 3 个主元素）

角色设计

Character Design

荷绿连衣裙 + 记录本 / 荷叶道具，发间荷叶形发夹，好奇微微侧头，活泼但不幼稚。

统一比例

上色规范

无粗黑描边，色块分层；暗部用同色系加深，不使用纯黑阴影。

03

视觉识别

Visual Identity

Logo、色彩、字体、纹样与图标共用同一套几何语言：圆角几何 + 无粗黑描边， 文字全部由 HTML / SVG 排版，不依赖图像模型生成中文。

Logo · 放大镜 + 古桥拱 + 水波，横版锁定与图标两种规格

色彩系统 · 5 主色：墨蓝 / 河青 / 荷绿 / 柿橘 / 宣米｜底色 60% · 河青+荷绿 25% · 墨蓝 10% · 柿橘 5%

字体规范 · Typography｜Display / Accent / Label / Body 四级

辅助纹样 · Pattern｜古桥 / 水波 / 荷叶 / 乌篷船

图标系统 · Icons｜放大镜 / 地图 / 记录本 / 古桥 / 荷叶…

05

系列总览

Series Overview

把 6 件 SKU 放回同一张货架：统一投影角度、统一留白率、统一构图重心， 是"系列"区别于"六张图"的地方。

产品矩阵 · Product Grid｜3 × 2 网格，同一视角、同一投影（左上光 45°）

01
同一角色比例

全部 SKU 上的角色来自同一套 1:2.9 比例文件，不逐图重画。

02
同一配色比例

底色 60% / 河青+荷绿 25% / 墨蓝 10% / 柿橘 5%，逐件可检。

03
同一构图重心

左上起手的构图方向，主标与角色压角位置统一。

04
同一留白率

画面留白 ≥ 35%，产品图统一左上光 45° 投影角度。
